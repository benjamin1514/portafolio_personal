Sobre mí

Soy desarrollador en formación enfocado en el ecosistema de Python y desarrollo web. Me apasiona crear proyectos bien estructurados, aprender metodologías de software y resolver necesidades concretas mediante código limpio.

Actualmente fortalezco mis habilidades en lógica de programación, diseño de interfaces claras y creación de aplicaciones funcionales.

Lo que ya sé

Estas son las herramientas y conocimientos que aplico en mis proyectos.

Lenguajes y Desarrollo Web

Python

Estoy aprendiendo a resolver tareas con variables, condiciones, ciclos y funciones. También puedo organizar datos y separar un programa en partes más fáciles de entender y mantener.

HTML5

Construyo la estructura de una página usando etiquetas semánticas para títulos, secciones, enlaces, imágenes y formularios. Procuro que el contenido tenga un orden claro y sea fácil de recorrer.

CSS3

Personalizo colores, tipografías, espacios y componentes para dar identidad visual a una página. Uso reglas responsive para que la interfaz se adapte a pantallas de distintos tamaños.

JavaScript

Añado interactividad mediante eventos y manipulación del DOM. Puedo actualizar contenido dinámico y controlar acciones de la interfaz, como la navegación móvil.

Conocimientos

Lógica de programación

Divido un problema en pasos pequeños, identifico qué datos necesito y defino cómo procesarlos. Aplico variables, condiciones y ciclos para convertir esos pasos en instrucciones.

Fundamentos de POO

Conozco los conceptos iniciales de clases y objetos, y cómo agrupar datos y comportamientos relacionados. Esto me ayuda a estructurar programas de forma más ordenada.

Desarrollo de interfaces

Organizo textos, botones, formularios y navegación para que las personas encuentren lo que buscan. También considero la adaptación a móviles y la claridad visual.

Resolución de problemas

Primero intento entender el objetivo y reproducir el problema; luego pruebo una solución y reviso el resultado. Si algo falla, uso el error como pista para corregir y volver a probar.
